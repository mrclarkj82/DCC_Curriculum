## Vocabulary and Misconceptions

- Node: A tool or image source represented as a box in a Fusion flow.
- MediaIn: An image entering the Fusion composition from timeline or media sources.
- MediaOut: The final image sent back to the timeline.
- Connection: A link carrying an image or mask between nodes.
- Viewer: A panel that can display the output of a selected node.
- Bypass: Temporarily disabling a tool to compare the result with the original.

Do not equate watching with doing. Explain that different page views share timeline work, nodes must connect to the final output, and paid tools are optional.

### Current Required Student Workflow

1. Keep the same saved ResolveFoundations project. Create a separate timeline named Foundations_FusionPractice using the teacher-supplied Fusion demo clips or approved substitute footage.
2. Watch 01:43:14-02:02:05. Pause after entering Fusion and after each connection/viewer demonstration. Select one practice clip before opening Fusion.
3. Locate MediaIn and MediaOut, the node workspace, viewers, Inspector, and clip frame range. Load MediaIn in one viewer and MediaOut in the other so you can compare input and output.
4. Insert one Blur or Color Corrector node between MediaIn and MediaOut. Check that both connections exist and make a small visible change in its Inspector.
5. Compare the effect enabled and bypassed, then return to Edit and verify the same clip shows the result. Keep the effect subtle or restore the original after documenting the comparison.

### Reflection and Differentiation

Reflection: In 2-3 sentences, trace your image through the three nodes and explain how the viewers helped you check the result.

Intervention: Use one short clip and a three-node Blur chain. Model input/output connections and viewing one node at a time before adding any branches.

Extension: Add a second simple effect and change the order. Predict the result, compare it in the viewer, and restore a purposeful version.

Teacher check: Ask the student to trace the actual connections and show MediaOut in Edit. A screenshot of disconnected boxes does not demonstrate a working effect.
