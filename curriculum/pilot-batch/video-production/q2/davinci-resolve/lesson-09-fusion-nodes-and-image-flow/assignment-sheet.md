# Fusion Image-Flow Checkpoint Assignment Sheet

## Objective

I can build and explain a simple MediaIn-to-effect-to-MediaOut node flow and verify the result on the Edit page.

## Watch, Pause, Practice

Open the assigned tutorial segment and your own DaVinci Resolve project together. Watch a short demonstration, pause, repeat the action, and check the result before continuing. Keep the same saved project through all eleven lessons and use separate Cut/Fusion practice timelines where directed. Watching alone does not complete the assignment. Assigned segment: 01:43:14-02:02:05.

- After opening Fusion: confirm you are working on the intended practice clip rather than the entire timeline.
- After inserting a node: trace an unbroken connection from MediaIn through the effect to MediaOut.
- After switching to Edit: check that the same clip shows the Fusion result without a separate render.

## Required Steps

1. Keep the same saved ResolveFoundations project. Create a separate timeline named Foundations_FusionPractice using the teacher-supplied Fusion demo clips or approved substitute footage.
2. Watch 01:43:14-02:02:05. Pause after entering Fusion and after each connection/viewer demonstration. Select one practice clip before opening Fusion.
3. Locate MediaIn and MediaOut, the node workspace, viewers, Inspector, and clip frame range. Load MediaIn in one viewer and MediaOut in the other so you can compare input and output.
4. Insert one Blur or Color Corrector node between MediaIn and MediaOut. Check that both connections exist and make a small visible change in its Inspector.
5. Compare the effect enabled and bypassed, then return to Edit and verify the same clip shows the result. Keep the effect subtle or restore the original after documenting the comparison.
6. Save. Submit a screenshot of the connected node chain and output, a short explanation of each node, and a before/after comparison in your evidence Doc. Submit its link and the DCC reflection; no export is required.
