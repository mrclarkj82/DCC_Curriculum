## Required Workflow

1. Reopen your ResolveFoundations project. Duplicate the existing mini-edit or create a separate four-clip timeline named Foundations_CutPractice so your polished edit stays available.
2. Watch 01:30:41-01:43:14 in short portions. Pause at Source Tape, the dual timeline, and Smart Insert to repeat the actions with your own media.
3. Browse a bin using Source Tape. Use the overview timeline to move to an edit, then use the detail timeline to inspect that same edit.
4. Select a source range, identify the highlighted edit point, and use Smart Insert once. Check where the clip landed; undo and repeat if the placement was unintended.
5. Trim and reorder the practice sequence into a clear 30-60 second, four-clip edit. Switch to Edit and verify that you are seeing the same timeline. Use mouse/keyboard controls; a Speed Editor is not required.
6. Save. Submit a Cut-page screenshot with both timeline views, a note about your Smart Insert and trim, and a two-sentence Cut/Edit workflow comparison in your evidence Doc. Submit the link and DCC reflection.
