## Vocabulary and Misconceptions

- Source Tape: A Cut-page view that lets you browse clips from a bin as one continuous source.
- Dual timeline: An overview and a detailed view of the same sequence, not two separate edits.
- Smart Insert: An insert action that uses the highlighted nearest edit point.
- Edit indicator: The highlight that shows which edit point a Cut-page action will affect.
- Ripple trim: A trim that closes or opens time by moving later clips.

Do not equate watching with doing. Explain that different page views share timeline work, nodes must connect to the final output, and paid tools are optional.

### Pause-and-Practice Prompts

- After Source Tape: find one usable source range without opening every clip separately.
- Before Smart Insert: point to the highlighted edit point and predict the placement.
- After returning to Edit: confirm the timeline name and edits match the Cut page.

### Current Required Student Workflow

1. Reopen your ResolveFoundations project. Duplicate the existing mini-edit or create a separate four-clip timeline named Foundations_CutPractice so your polished edit stays available.
2. Watch 01:30:41-01:43:14 in short portions. Pause at Source Tape, the dual timeline, and Smart Insert to repeat the actions with your own media.
3. Browse a bin using Source Tape. Use the overview timeline to move to an edit, then use the detail timeline to inspect that same edit.
4. Select a source range, identify the highlighted edit point, and use Smart Insert once. Check where the clip landed; undo and repeat if the placement was unintended.
5. Trim and reorder the practice sequence into a clear 30-60 second, four-clip edit. Switch to Edit and verify that you are seeing the same timeline. Use mouse/keyboard controls; a Speed Editor is not required.
6. Save. Submit a Cut-page screenshot with both timeline views, a note about your Smart Insert and trim, and a two-sentence Cut/Edit workflow comparison in your evidence Doc. Submit the link and DCC reflection.

### Reflection and Differentiation

Reflection: In 2-3 sentences, explain where Smart Insert placed your clip and which page you would choose for a fast classroom news update.

Intervention: Use four supplied clips and a duplicate timeline. Model the highlighted edit point before a single Smart Insert, then check the result in Edit. Skip hardware-specific demonstrations.

Extension: Assemble the same four clips once in Cut and once in Edit. Compare the number of actions and clarity of the result without treating speed alone as quality.

Teacher check: Check the actual shared timeline in Cut and Edit and ask the student to predict a Smart Insert. No Speed Editor purchase or shortcut mapping is required.
